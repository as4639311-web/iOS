# FMS/EMS — الإصدار 4 (PWA + تجربة آيفون)

نظام إدارة الأسطول والمعدات: أصول موسّعة، مواعيد صيانة، مخزون، TCO، مزادات، PWA قابل للتثبيت على iPhone وAndroid.

**المستودع:** https://github.com/as4639311-web/iOS

## ⚠️ أمان
- لا ترفع `config.php` إلى Git (موجود في `.gitignore`).
- انسخ `config.sample.php` → `config.php` على الخادم واملأ بيانات قاعدة البيانات فقط هناك.
- غيّر كلمة مرور قاعدة البيانات من لوحة الاستضافة إن سبق تداولها.

## الملفات في هذا المستودع
| الملف | الوصف |
|-------|--------|
| `index.php` | التطبيق الكامل (ارفعه من الحزمة إن لم يظهر هنا بسبب الحجم) |
| `config.sample.php` | قالب الاتصال بقاعدة البيانات |
| `manifest.json` | PWA + اختصارات iOS |
| `sw.js` | Service Worker |
| `offline.html` | صفحة عدم الاتصال |
| `.htaccess` | حماية مجلدات + DirectoryIndex |
| `db/migration_v4.sql` | مرجع SQL للإصدار 4 |
| `icons/` | أيقونات التطبيق وشاشات الإقلاع (من ملف zip) |

## التشغيل على Awardspace
1. ارفع محتويات المشروع إلى `public_html` (أو مجلد فرعي).
2. انسخ `config.sample.php` إلى `config.php` واملأ:
   - `DB_HOST`, `DB_NAME`, `DB_USER`, `DB_PASS`
3. افتح الموقع — الجداول تُنشأ تلقائياً.
4. أنشئ حساب المدير الأول.

## تثبيت كتطبيق آيفون
1. افتح الرابط في **Safari**.
2. مشاركة ← **إضافة إلى الشاشة الرئيسية**.
3. يفتح كتطبيق مستقل (Standalone).

## الميزات الرئيسية (v4)
- حقول آليات موسّعة (لوحة، ملكية، قسم، سائق، صيانة قادمة، صورة…)
- **حجز مواعيد صيانة** مع حالات وموافقات وصلاحيات من الخادم
- تجربة PWA بأسلوب iOS (safe-area، شريط سفلي، تذكرني)
- وحدات سابقة: أوامر شغل، مخزون، TCO، مزادات، وثائق، سجل تدقيق

## الرخصة والاستخدام
للاستخدام الداخلي للفريق — لا تضع أسرار قاعدة البيانات في المستودع.
